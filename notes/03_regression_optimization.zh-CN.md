## 一、 核心知识链：从线性预测到梯度下降

1. **线性预测模型（Hypothesis）**：给定特征矩阵 $X \in \mathbb{R}^{n \times d}$，给每个样本拼接一列常数 `1`（把截距/偏置项 $b$ 并入权重向量 $w$），模型的预测输出就是矩阵乘法：
   $$\hat{y} = Xw$$
2. **损失函数（Loss Function — 均方误差 MSE）**：怎么衡量当前权重 $w$ 猜得好不好？算预测值 $\hat{y}$ 与真实值 $y$ 之间差距的平方平均：
   $$L(w) = \frac{1}{n} \|Xw - y\|_2^2$$
3. **方法 A：解析解（正规方程 Closed-form Solution）**：对于简单线性回归，可以直接令导数为 0 一步算出最优解 $w^* = (X^T X)^{-1} X^T y$。但在实际工程中，直接求矩阵逆既慢又容易因为特征共线性（奇异矩阵）而失败，因此通常用数值稳定的最小二乘求解器 `np.linalg.lstsq` 或添加正则项。
4. **方法 B：梯度下降（Gradient Descent — 现代深度学习通用引擎）**：当模型变成非线性神经网络或参数量高达数亿时，根本不存在一步到位的解析解。我们计算损失函数对参数的梯度：
   $$\nabla_w L(w) = \frac{2}{n} X^T (Xw - y)$$
   然后沿梯度的反方向（下坡方向）迭代更新参数：
   $$w \leftarrow w - \eta \nabla_w L(w)$$
   其中 $\eta$（Learning Rate，学习率）控制每一步迈多大。

```python
import numpy as np

# 构造带偏置列 1 的特征矩阵 X 与真实目标 y (真实规律: y = 1 + 1 * x)
X = np.array([[1., 1.], [1., 2.], [1., 3.]])
y = np.array([2., 3., 4.])

w = np.zeros(2)
lr = 0.05
for _ in range(200):
    grad = (2 / len(y)) * X.T @ (X @ w - y)
    w -= lr * grad
print('Gradient descent weights:', w)  # 逼近真实参数 [1., 1.]
```

## 二、 优化器演进：BGD vs. SGD vs. Mini-batch vs. Adam

| 优化方式 | 每次更新使用多少数据？ | 优缺点与在 AI 中的地位 |
|---|---|---|
| **批量梯度下降 (Batch GD)** | 全部训练集样本 $n$ | 方向最准，但如果有 1000 万条数据，算一步就要等半天，内存也装不下 |
| **随机梯度下降 (SGD)** | 每次只抽 $1$ 个样本 | 更新极快，但单个样本噪声大，下山路线剧烈震荡 |
| **小批量梯度下降 (Mini-batch GD)** | 每次抽一小批（如 `batch_size=32/64`） | **现代深度学习标配**：兼顾 GPU 矩阵并行效率与梯度稳定性 |
| **Adam 自适应优化器** | Mini-batch + 一阶动量（惯性）+ 二阶矩（自适应步长） | 为每个参数自动调节有效学习率，是 PyTorch 与大模型训练最常用的默认优化器 |

## 三、 欠拟合、过拟合与正则化（Polynomial & Ridge）

1. **多项式特征扩展（Polynomial Regression）**：如果真实规律是弯的曲线，线性模型能拟合吗？可以！只要把原始特征 $x$ 映射为 $\phi(x) = [1, x, x^2, \dots, x^d]$，再套用线性回归 $\hat{y} = \phi(X)w$ 即可（因为它对参数 $w$ 依然是线性的）。
2. **偏差-方差权衡（Bias–Variance Tradeoff）**：
   - 阶数 $d$ 太低（如用直线拟合抛物线）：训练集和测试集误差都很高 ➡️ **欠拟合（Underfitting / 高偏差）**；
   - 阶数 $d$ 太高（如用 15 阶多项式强行穿过每一个噪声点）：训练集误差接近 0，但一到测试集误差暴涨 ➡️ **过拟合（Overfitting / 高方差）**。
3. **正则化（Regularization — 给失控的权重套上缰绳）**：
   - 为了防止高阶多项式或高维特征的权重 $w_j$ 变得巨大而产生剧烈震荡，**岭回归（Ridge / L2 正则化）** 在损失函数后加上权重的平方和惩罚项（截距项 $w_0$ 通常不惩罚）：
     $$L_{\text{Ridge}}(w) = \frac{1}{n}\|Xw - y\|_2^2 + \lambda \sum_{j \ge 1} w_j^2$$
   - $\lambda$（在 sklearn 中叫 `alpha`）越大，惩罚越重，曲线越平缓；另外 **Lasso（L1 正则化，$\lambda \sum |w_j|$）** 还能将不重要的特征权重直接压缩为 `0`，实现自动特征筛选。
   - **重要前提**：由于正则化对所有权重一视同仁地惩罚，且梯度下降对特征量纲极其敏感，**使用梯度下降或正则化前必须在训练集上做 `StandardScaler` 标准化！**

## 四、 训练异常现象诊断速查表

| 观察到的异常现象 | 背后原因与排查清单 |
|---|---|
| 训练损失变成 `nan` 或 `inf` | **学习率 $\eta$ 过大**导致越过谷底发散；或者输入数据中存在未清理的极大异常值/`NaN` |
| 梯度下降收敛极其缓慢 | 特征尺度差异悬殊（未做 `StandardScaler`），导致损失等高线变成狭长峡谷，梯度来回Z字震荡 |
| 训练集 MSE 极小，测试集 MSE 极大 | 典型**过拟合**；应降低多项式阶数 $d$、增大正则化强度 `alpha` 或增加训练样本 |
| 解析解与梯度下降算出的 $w$ 不一致 | 检查是否使用了完全相同的特征矩阵（如是否都含截距列）、梯度下降迭代步数是否足够收敛 |
| $X^T X$ 求逆报错（Singular matrix） | 特征之间存在完全共线性或特征数大于样本数（秩亏）；改用 `np.linalg.lstsq` 或 `Ridge` |
