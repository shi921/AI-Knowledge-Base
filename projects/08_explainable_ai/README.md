# SHAP: Global and Local Model Explanations

```bash
python projects/08_explainable_ai/main.py
# Optional network-based UCI Mushroom dataset (requires ucimlrepo)
python projects/08_explainable_ai/main.py --dataset mushroom
```

The default built-in breast cancer dataset generates SHAP figures offline. This project demonstrates explanation methods only, **not medical diagnosis**. SHAP explains model-attributed prediction contributions, not causal effects.
