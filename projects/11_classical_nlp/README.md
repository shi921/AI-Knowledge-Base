# Classical NLP: BoW, TF-IDF, N-grams, and Perplexity

```bash
python projects/11_classical_nlp/main.py --ngram 2
```

Small built-in text samples illustrate text classification and a statistical N-gram language model. Optional `word_embeddings_optional.py` needs an **explicitly provided trustworthy** Gensim KeyedVectors (`.kv`) path. The toy dataset is not a meaningful performance benchmark.

**Related notes:** [Chapter 09](../../notes/09_classical_nlp_language_models.md).
